# Book CRUD Application

A simple **full-stack CRUD application** to manage books. Users can **create, read, update, and delete** books. Built using **React.js** for frontend and **Node.js/Express.js** for backend (or API integration), with state management using **Context API / Redux**.

---

## Features

- **Add a Book** – Users can add new books with title, author, and description.
- **View Books** – Display all books in a list with details.
- **Update Book** – Edit existing book information.
- **Delete Book** – Remove books from the list.
- **Responsive UI** – Works well on desktop and mobile devices.

---

## Tech Stack

- **Frontend:** React.js, Tailwind CSS (for styling)
- **Backend:** Express.js / API server
- **State Management:** Context API / Redux
- **Routing:** React Router DOM
- **Data Storage:** JSON Server / MongoDB (if connected)
- **Others:** Axios (for API calls)
